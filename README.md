# 📚 Books On The Table

Aplicação Full Stack desenvolvida em Python para gerenciar livros lidos, registrar avaliações e acompanhar estatísticas de leitura.

## 🚀 Tecnologias

- Python
- FastAPI
- NiceGUI
- PostgreSQL
- SQLAlchemy
- Docker

## 📌 Funcionalidades

- Cadastrar livros
- Listar livros
- Buscar livro por ID
- Atualizar livros
- Excluir livros
- Registrar avaliação dos livros

## 🛠️ Em desenvolvimento

Projeto desenvolvido para praticar Python, APIs REST, banco de dados, Docker e arquitetura de aplicações.
